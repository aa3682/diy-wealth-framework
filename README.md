# The DIY Wealth Framework

Welcome to the open-source playbook for self-directed financial planning[span_3](start_span)[span_3](end_span). This framework is designed to give DIY investors the exact systems, calculators, and strategies needed to build and manage their own wealth architecture[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span). 

## Core Systems
* **Financial Defense** - Emergency reserves, high-interest debt elimination, and essential insurance coverage[span_6](start_span)[span_6](end_span).
* **Cash Flow Systems** - Income routing, automated savings, and dynamic budgeting[span_7](start_span)[span_7](end_span).
* **Wealth Accumulation** - Asset allocation, index fund mechanics, and portfolio construction (including digital asset ETFs)[span_8](start_span)[span_8](end_span).
* **Tax Efficiency** - Account sequencing, tax-loss harvesting, and sheltering strategies[span_9](start_span)[span_9](end_span).
* **Retirement Runway** - Safe withdrawal rates, compounding math, and financial independence targets[span_10](start_span)[span_10](end_span).
* **Legacy Mechanics** - Beneficiary optimization, basic trusts, and wealth transfer[span_11](start_span)[span_11](end_span).

## Tech Stack
This documentation site is powered by Nextra, a Static Site Generator built on Next.js. The content is written in MDX, allowing for the integration of interactive React components and dynamic financial calculators directly into the text.
